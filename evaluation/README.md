# Evaluation and Comparison

This directory contains language-neutral evaluation and comparison tools.
Python inference remains under `python/`, and C++ inference remains under
`cpp/`.

Run COCOeval on predictions generated by the C++ executable:

```bash
python evaluation/evaluate_cpp_coco_person.py
```

Compare the completed Python and C++ metric summaries:

```bash
python evaluation/compare_python_cpp.py
```

The comparison is written to:

```text
results/yolo11n/python_vs_cpp_comparison.json
```

The two input files use an aligned JSON schema:

```text
results/yolo11n/python_coco_person_metrics.json
results/yolo11n/cpp_coco_person_metrics.json
```
